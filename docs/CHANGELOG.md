# 更新日志

本文档记录了 Personal Disk 项目的所有重要变更。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### 新增
- 统一配置管理系统
- 多环境配置支持（开发、测试、生产）
- 环境变量覆盖机制
- Docker 多环境部署支持
- 自动化启动脚本
- 配置验证机制
- 完整的项目文档

### 变更
- 重构了配置加载逻辑，移除硬编码
- 优化了 Docker 构建过程
- 改进了错误处理和日志记录
- 更新了项目目录结构

### 移除
- 删除了不必要的临时文件
- 移除了旧的启动脚本

## [1.0.0] - 2024-03-25

### 新增
- 基础的个人网盘功能
- 文件上传、下载、删除、重命名
- 管理员认证系统
- Web 用户界面
- MySQL 数据库支持
- Docker 容器化部署
- 文件类型和大小限制

### 技术栈
- 后端：Go 1.20+
- 数据库：MySQL 8.0+
- 前端：原生 HTML/CSS/JavaScript
- 部署：Docker + Docker Compose

### 变更类型
- **新增** (Added) - 新功能
- **变更** (Changed) - 对现有功能的变更
- **弃用** (Deprecated) - 即将移除的功能
- **移除** (Removed) - 已移除的功能  
- **修复** (Fixed) - 任何 bug 修复
- **安全** (Security) - 安全相关的修复
